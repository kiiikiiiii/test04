요청: 북마크 서비스의 인덱스 페이지를 UI로 구축해줘.
- 페이지 구성: 
- 상단 헤더 좌측에 "가벼운 한 기"라는 텍스트 로고를 넣어주고, 우측에 "+ADD LINK"버튼 만들어줘.
- 좌측 사이드바에는"ALL"버튼과 폴더 리스트 만들어줘.
- 메인 섹션에는 등록된 링크들을 그리드 형태로 배치해줘.
- 주의사항:
- 컴포넌트 단위로 적절히 분할해서 구현해줘.
- 실행 결과는 컴포넌트 단위로 보고해.


요청: ADD LINK 버튼을 눌렀을 때 새 링크 등록 페이지를 구현해줘.
- 페이지 주소: /NEW
- 인덱스 페이지의 ADD LINK 버턴을 누르면 이 페이지로 이동
- 헤더와 사이드바는 인덱스 페이지와 동일
- 메인 섹션에는 링크 입력 인풋과 저장 버튼 배치
- 주의사항: 이미 만들어 둔 컴포넌트를 최대한 활용해줘 (중복 컴포넌트 방지)
